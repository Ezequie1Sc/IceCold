## Acerca del proyecto

**Técnico Miguel Salazar** es una landing page moderna creada para presentar servicios de climatización de forma profesional, mostrando trabajos realizados, servicios disponibles y canales de contacto directo para clientes potenciales.

La web está enfocada en transmitir confianza, experiencia y facilitar la solicitud de cotizaciones mediante WhatsApp.

---

## Características

- Diseño moderno y responsive.
- Sección de servicios.
- Galería de instalaciones realizadas.
- Galería de mantenimientos.
- Evidencia visual de reparaciones.
- Integración con WhatsApp.
- Optimización para dispositivos móviles.
- Navegación rápida e intuitiva.

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/Ezequie1Sc/IceCold.git
````

Entrar al proyecto:

```bash
cd IceCold
```

Abrir el archivo principal:

```bash
index.html
```

O ejecutar utilizando **Live Server** en Visual Studio Code.
